01Basics

Determinant is square only

Only square matrices have determinants.

  • CBSE writing: First check order before writing determinant.
  • JEE focus: Non-square determinant questions are invalid.
  • Common trap: A 2 x 3 matrix has no determinant.
022 x 2

Second order determinant

For [[a,b],[c,d]], determinant is ad-bc.

  • CBSE writing: Write diagonals clearly.
  • JEE focus: Use it for area scale and inverse.
  • Common trap: Do not write ac-bd.
03Expansion

Cofactor expansion

A third order determinant can be expanded along any row or column.

  • CBSE writing: Choose a row or column with zeros.
  • JEE focus: Smart expansion saves time.
  • Common trap: Cofactor signs alternate.
04Properties

Row and column properties

Interchanging two rows changes sign; multiplying a row by k multiplies determinant by k.

  • CBSE writing: State the property used in simplification.
  • JEE focus: Properties are faster than direct expansion.
  • Common trap: Adding multiple of one row to another does not change determinant.
05Zero

When determinant is zero

If two rows or columns are identical or proportional, determinant is zero.

  • CBSE writing: Use this property before expanding.
  • JEE focus: Detect dependent rows quickly.
  • Common trap: Only one pair being similar is enough.
06Cofactor

Minor and cofactor

Minor M_ij is determinant after deleting row i and column j; cofactor A_ij=(-1)^(i+j)M_ij.

  • CBSE writing: Write sign factor carefully.
  • JEE focus: Cofactors build adjoint.
  • Common trap: Minor and cofactor differ by sign.
07Inverse

Adjoint formula

For square A, A adj(A)=adj(A) A=|A|I.

  • CBSE writing: Use inverse A^-1=adj(A)/|A| when |A| is not zero.
  • JEE focus: Adjoint identities are common in objective questions.
  • Common trap: Adjoint is transpose of cofactor matrix.
08Application

Area and equations

Determinants give area of triangle and solve systems using inverse or Cramer style methods.

  • CBSE writing: For area, take absolute value.
  • JEE focus: Zero determinant means collinear points in area questions.
  • Common trap: Area cannot be negative.

Formula sheet

High-yield formulas with exact usage conditions.

Use these as quick revision cards before solving examples.

2 x 2

Second order determinant

|a b; c d| = ad - bc

Cross product difference.

  • Example: |3 1; 2 4|=12-2=10.
  • Trap: Order of products matters.
3 x 3

Expansion along first row

|A| = a11 A11 + a12 A12 + a13 A13

Multiply entries by their cofactors.

  • Example: Choose row with maximum zeros.
  • Trap: Use cofactors, not just minors.
Sign

Cofactor sign

A_ij = (-1)^(i+j) M_ij

Checkerboard signs are + - + / - + - / + - +.

  • Example: A12 = -M12.
  • Trap: Forgetting the negative sign.
Property

Row swap

Swapping two rows changes sign of determinant

One interchange multiplies determinant by -1.

  • Example: R1 <-> R2 changes D to -D.
  • Trap: Two swaps bring original sign back.
Property

Scalar row

If one row is multiplied by k, determinant is multiplied by k

Factor common row multiplier outside.

  • Example: Common 3 in one row makes determinant 3 times smaller after factoring.
  • Trap: Multiplying whole determinant by k differs from multiplying every row.
Zero

Proportional rows

Two proportional rows or columns => determinant 0

Rows are dependent.

  • Example: [1,2,3] and [2,4,6] make determinant zero.
  • Trap: Must compare full row or column.
Inverse

Inverse by adjoint

A^-1 = adj(A)/|A|, |A| != 0

Adjoint divided by determinant.

  • Example: Use for 2 x 2 and 3 x 3 inverse.
  • Trap: Undefined when determinant is zero.
Area

Area of triangle

Area = 1/2 | x1(y2-y3)+x2(y3-y1)+x3(y1-y2) |

Determinant formula for triangle area.

  • Example: If determinant part is 12, area is 6.
  • Trap: Take absolute value.

Derivation bank

Proofs that can be reproduced in exams.

Open a proof, follow the steps, and check the final result.

Derive 2 x 2 determinant formula
  1. Take determinant |a b; c d|.
  2. Multiply entries on main diagonal: ad.
  3. Multiply entries on other diagonal: bc.
  4. Subtract to get ad-bc.

Final: ad-bc

Shortcut: Main diagonal minus other diagonal.

Warning: Works only for 2 x 2.

Show determinant is zero when two rows are identical
  1. Let determinant be D with two identical rows.
  2. Interchange those two identical rows.
  3. The determinant value stays D because entries did not change.
  4. But row interchange changes sign, so D=-D and D=0.

Final: D=0

Shortcut: Swap identical rows.

Warning: Rows must be exactly identical.

Prove A adj(A)=|A|I idea
  1. Entry on diagonal becomes expansion of determinant along a row.
  2. So diagonal entries are |A|.
  3. Off-diagonal entries represent expansion with two equal rows.
  4. Those off-diagonal determinants are zero.

Final: A adj(A)=|A|I

Shortcut: Use cofactor expansion.

Warning: Adjoint is transpose of cofactor matrix.

Area formula for triangle
  1. Write points in determinant with last column 1.
  2. Expand determinant.
  3. The signed double area is obtained.
  4. Take absolute value and divide by 2.

Final: Area is half absolute determinant.

Shortcut: Use shoelace determinant.

Warning: Absolute value is required.

CBSEEasy

1. Find |3 1; 2 4|.

Answer: 10

3*4 - 1*2 = 12-2=10.

Trap: Do not write 3*2 - 1*4.

BasicsEasy

2. Can a 2 x 3 matrix have a determinant?

Answer: No

Only square matrices have determinants.

Trap: Do not confuse matrix with determinant.

PropertyMedium

3. What happens to determinant if two rows are interchanged?

Answer: Sign changes

One row swap multiplies determinant by -1.

Trap: Magnitude stays same but sign changes.

PropertyMedium

4. If two rows are equal, what is determinant?

Answer: 0

Interchanging equal rows changes sign but determinant remains same, so D=0.

Trap: Do not expand unnecessarily.

CofactorMedium

5. What is cofactor A12 in terms of minor M12?

Answer: -M12

A12=(-1)^(1+2)M12=-M12.

Trap: Sign is negative.

InverseMedium

6. When is A^-1=adj(A)/|A| valid?

Answer: When |A| != 0

Inverse exists only for non-singular square matrix.

Trap: Do not divide by zero determinant.

AreaMedium

7. If determinant part for triangle area is -14, what is area?

Answer: 7

Area = 1/2|-14|=7.

Trap: Area is not negative.

JEEHard

8. If every entry of a 3 x 3 determinant is multiplied by 2, determinant becomes what?

Answer: 8 times

Each of 3 rows is multiplied by 2, so determinant is multiplied by 2^3=8.

Trap: Not just 2 times.

PropertyHard

9. What operation does not change determinant: Ri -> Ri + kRj?

Answer: It remains same

Adding multiple of one row to another row leaves determinant unchanged.

Trap: Multiplying a row by k is different.

CofactorMedium

10. What is adjoint of A?

Answer: Transpose of cofactor matrix

Find cofactor matrix, then transpose it.

Trap: Do not forget transpose.

CBSEMedium

11. What is determinant of identity matrix of order 3?

Answer: 1

Product of diagonal entries is 1.

Trap: Identity determinant is not 3.

ProofHard

12. Prove determinant is zero if two columns are proportional.

Answer: Use column property

Factor multiplier and get two identical columns, hence determinant zero.

Trap: Proportional means full columns match by one multiplier.
